# claude-zone — рабочие файлы Claude по проекту

Одна папка под всё, что генерит/ведёт Claude по этому проекту, чтобы её можно было **целиком** включать или выключать из git.

## Содержимое
- `FINDINGS.md` — локальные находки проекта (неочевидное поведение, обходы, решения ревью). Append-only. Полезное мигрирует в централь `G:\Work-5corners\claude zone\personal-claude-knowledge\`.
- (по мере надобности) `docs/` — проектные разборы/архитектура.

`NEXT_SESSION.md` лежит в **корне проекта** (не здесь) — этого требует скилл `continue-session`, он читает `[корень]/NEXT_SESSION.md`.

## Тоггл git
В корневом `.gitignore` есть блок-переключатель:
```
# --- Claude artifacts (раскомментировать, чтобы ИСКЛЮЧИТЬ из git) ---
# claude-zone/
```
Сейчас закомментировано → папка **попадает в git**. Раскомментируй строку, чтобы перестала.
